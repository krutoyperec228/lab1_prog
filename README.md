# Спортивный клуб «Олимп»

Консольное приложение на Python для управления спортивным клубом:
тренеры, спортсмены, секции и связи между ними. Поддерживает сохранение
и загрузку данных в форматах **JSON** и **XML**, автоматически сохраняет
изменения после каждой операции.


---

## Возможности

- **Тренеры** — добавление, просмотр, удаление.
- **Спортсмены** — добавление, просмотр, удаление.
- **Секции** — добавление, просмотр, удаление, ограничение по числу участников.
- **Запись спортсмена в секцию** с проверкой:
  - существует ли секция и спортсмен,
  - не переполнена ли секция,
  - не записан ли спортсмен повторно.
- **Удаление с синхронизацией связей**:
  - удаление спортсмена убирает его из всех секций,
  - удаление секции убирает её из списков у всех спортсменов,
  - удаление тренера запрещено, пока он ведёт хотя бы одну секцию.
- **Автосохранение** в `club.json` и `club.xml` после каждого изменения.
- **Загрузка** из JSON или XML при старте (с проверкой ссылочной целостности).
- **Обработка ошибок**: свои исключения для валидации, дубликатов,
  переполнения секции и отсутствующих сущностей.

## Структура проекта

```
.
├── main.py          # консольный интерфейс, меню
├── models.py        # модели предметной области и свои исключения
├── club.py          # класс SportsClub: CRUD + JSON/XML
├── pyproject.toml   # конфигурация проекта для uv
├── uv.lock          # зафиксированные версии зависимостей
```

### Модули

| Файл | Что содержит |
|---|---|
| `models.py` | Исключения (`SportsClubError`, `NotFoundError`, `DuplicateError`, `SectionFullError`, `ValidationError`), классы `Person`, `Coach`, `Athlete`, `Section`, функции `*_from_dict`. |
| `club.py`   | Класс `SportsClub` — хранилище тренеров, спортсменов и секций, CRUD, запись/чтение JSON и XML. |
| `main.py`   | Точка входа: `menu()`, ввод/вывод в консоли, обработка исключений. |

## Установка и запуск



### Клонировать репозиторий и запустить

```bash
git clone <URL_репозитория>
cd <папка_проекта>

uv sync          # создаст .venv и поставит зависимости по uv.lock
uv run main.py   # запустит программу в этом окружении
```

Всё. `uv sync` сам скачает нужную версию Python (если её нет),
создаст виртуальное окружение `.venv` и установит зависимости из `uv.lock`.



## Как пользоваться

При старте программа спросит:

```
Загрузить предыдущие данные из файла? (y/n):
```

- `y` — попробует загрузить `club.json`, если не получится — `club.xml`,
  если и его нет — начнёт с пустого клуба.
- `n` — начнёт с пустого клуба.

После этого появится главное меню:

```
1.  Добавить тренера
2.  Добавить спортсмена
3.  Добавить секцию
4.  Записать спортсмена в секцию
5.  Удалить тренера
6.  Удалить спортсмена
7.  Удалить секцию
8.  Загрузить из JSON
9.  Загрузить из XML
10. Показать всю информацию
0.  Выход
```

## Обработка ошибок

Все ошибки — наследники `SportsClubError`, поэтому в `main.py` их можно
ловить как по отдельности, так и общим `except SportsClubError`:

| Исключение | Когда возникает |
|---|---|
| `ValidationError` | Некорректные данные при создании объекта (пустое имя, возраст вне 1–100, `max_size <= 0`, битые ссылки при загрузке). |
| `DuplicateError` | Попытка добавить сущность с уже существующим `id` или повторно записать спортсмена в секцию. |
| `NotFoundError` | Обращение к несуществующему тренеру / спортсмену / секции. |
| `SectionFullError` | Запись в секцию, где уже достигнут `max_size`. |

Дополнительно `main.py` ловит `FileNotFoundError` / `PermissionError`
при работе с файлами и `KeyboardInterrupt` при выходе по `Ctrl+C`.

## Особенности реализации

- **ООП-модель**: `Person → Coach`, `Person → Athlete`, отдельный класс `Section`.
  `SportsClub` хранит три словаря `{id: объект}`.
- **Инкапсуляция**: внутренние поля с префиксом `_`; доступ к имени —
  через методы `get_name()`.
- **Аннотации типов** у всех публичных методов и `__init__`.
- **Атомарная загрузка**: данные сначала читаются во временные структуры,
  проверяются `_check_links()`, и только потом присваиваются полям клуба —
  если файл битый, состояние клуба не портится.
- **Автосохранение** после каждой успешной операции; при ошибке ввода
  данные не пишутся.
- **Никаких сторонних зависимостей** — только стандартная библиотека.
- **uv** — управление окружением и запуском (см. `pyproject.toml` и `uv.lock`).
- **Соблюдение правил написания PEP 8**
